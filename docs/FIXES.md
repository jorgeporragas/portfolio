# FIXES

Fixes no test can hold, grouped by area. Read an area's entries before touching it, and never
undo one (`.claude/rules/flow.md`). A fix a test can hold gets the test instead.

Each entry is a level-2 heading, `Area: what broke`, then four lines:

- **Symptom:** what a visitor or developer saw.
- **Cause:** why it happened.
- **Fix:** what changed, with the pull request.
- **Why no test:** what makes it impossible or impractical to test.
